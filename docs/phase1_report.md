# Phase 1 Report — Water Quality Fingerprinting (ML, XAI & Dashboard)

## Objective
Develop a machine learning system that attributes water pollution to likely
sources (sewage/domestic, industrial, agricultural runoff, natural background)
using public CPCB / Tamil Nadu PCB water quality datasets, with SHAP-based
explainability and a web dashboard for visualization.

## Status
- [ ] CPCB / TN PCB dataset downloaded and placed in `ml-pipeline/data/raw/`
- [ ] Preprocessing pipeline validated on real data
- [ ] Fingerprint feature vectors built
- [ ] RF + XGBoost trained and evaluated
- [ ] SHAP explainability integrated
- [ ] FastAPI backend serving predictions
- [ ] React dashboard functional
- [ ] Paper drafted and submitted
